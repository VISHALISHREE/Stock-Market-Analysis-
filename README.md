# Stock-Market-Analysis
Processed structured and unstructured financial datasets using Spark, PySpark, and Hadoop. Performed data cleaning, validation, integration, and transformation. Built interactive dashboards and visualizations using Power BI and Tableau to generate actionable insights, support investment analysis, and improve decision-making efficiency.


## Features
- Process structured and unstructured financial datasets using **Spark, PySpark, and Hadoop**.
- Perform **data cleaning, validation, integration, and transformation** for high-quality analysis.
- Build interactive **dashboards and visualizations** using **Power BI** and **Tableau**.
- Generate **actionable insights** to support investment analysis and improve decision-making efficiency.

## Technologies Used
- **Big Data & Data Engineering:** Spark, PySpark, Hadoop, Pandas, NumPy  
- **Data Visualization & Analytics:** Power BI, Tableau  
- **Programming Languages:** Python  

## Project Highlights
- Efficiently handled large financial datasets for analysis.  
- Implemented ETL pipelines to streamline data processing.  
- Created visualizations that simplify complex financial information.  
- Delivered insights that aid in investment strategy planning.

## Skills Gained
- Data cleaning, validation, and integration  
- Big Data processing and pipeline creation  
- Interactive dashboard design and visualization  
- Financial data analysis and interpretation
